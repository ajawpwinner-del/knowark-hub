# 架构说明

## 组成

```
┌──────────── 手机：知舟 ────────────┐        ┌───────────────── Windows 电脑 ─────────────────┐
│ 文档解析（MinerU 本地部署）        │        │ 知舟服务台（Tauri 2）                          │
│ 网络搜索（SearXNG）                │  局域网 │  ├─ 界面：React + 书院设计令牌                  │
│ 知识检索（外部向量模型）           │ ──────▶ │  ├─ 网关：Rust axum，0.0.0.0:8765，Bearer Key   │
│ 设置 → 连接服务台（扫码配对）      │  8765  │  └─ 管理：docker CLI、环境体检、托盘           │
└────────────────────────────────────┘        │        │ 127.0.0.1                             │
                                              │  ┌─────┴─────┬──────────────┬──────────────┐   │
                                              │  │ MinerU 4  │ SearXNG      │ Ollama       │   │
                                              │  │ :8800     │ :8888        │ :11434       │   │
                                              │  └───────────┴──────────────┴──────────────┘   │
                                              │        Docker Desktop（WSL 2）                 │
                                              └────────────────────────────────────────────────┘
```

- **界面**（`src/`）：React 18 + TypeScript。服务目录只有一份 `src/catalog/services.json`，界面与 Rust 端共用。纯浏览器打开时使用演示数据，便于调界面。
- **后端**（`src-tauri/src/`）：
  - `docker.rs`：经 docker CLI 拉取 / 构建镜像、运行与管理容器（容器名 `knowark-<id>`，标签 `knowark.hub=1`）；
  - `gateway.rs`：兼容网关，见 [网关接口](gateway-api.md)；
  - `ollama.rs`：模型列表、下载进度、在线模型库、维度实测与截取；
  - `env_check.rs`、`netinfo.rs`、`health.rs`、`trial.rs`：环境体检、局域网地址与防火墙、可用性检查、试一试；
  - `secrets.rs`：网关 Key 存取（Windows 凭据管理器）；
  - `settings.rs`：设置文件（程序目录下 `settings.json`，不可写时退回 `%LOCALAPPDATA%\KnowArkHub`）。

## 设计取舍

**为什么用 Docker？** 三项服务分别依赖 Python 科学计算栈、Go 与模型运行时，原生打包维护成本极高。容器让安装、卸载干净可控，也方便切换 CPU / GPU 版本。代价是需要 Docker Desktop，服务台用环境体检把这一步讲清楚。

**为什么要网关？** 手机端只需记住一个地址和一个 Key；各服务容器只监听 `127.0.0.1`，局域网暴露面只有网关。网关还负责协议适配：

- 把 MinerU 返回的本机上传地址改写为网关地址，手机才能直接上传；
- 在知舟未指定维度时按服务台设置截取向量维度；
- 统一鉴权（Bearer / Basic）。

**为什么文档解析走异步接口？** CPU 上 MinerU 标准档约每页 20 秒，单次请求的超时（知舟为 60 秒）对多页文档必然不够。原生 V1 接口「上传 → 任务 → 轮询」不受此限制。

**为什么没有图片识别（OCR）？** 曾尝试部署 PaddleOCR，但其官方镜像放在国内对象存储上，大层下载频繁超时，小白难以排障；扫描版 PDF 已由 MinerU 的内置识别覆盖。

**网络与代理**：Docker Hub 镜像直连失败时自动改用国内镜像源；容器统一通过 Docker Desktop 的内置转发代理 `http.docker.internal:3128` 出网，它会转给 Docker Desktop 里配置的代理，未配置时直连。

## 安全边界

- Key：40 位随机字母数字，前缀 `ka-`，只存 Windows 凭据管理器，可随时更换（旧 Key 立即失效）。
- 防火墙：「允许访问」只为网关端口添加「专用网络」入站规则，需管理员确认。
- 日志：网关不记录请求内容、搜索词与 Key。
- 服务台不收集任何遥测数据。
