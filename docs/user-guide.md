# 使用指南

这份指南假设你从没用过 Docker，按顺序做一遍即可。全程大约 30 分钟，其中大部分时间在下载。

## 1. 准备电脑

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 2004（内部版本 19041）及以上，推荐 Windows 11 |
| 内存 | 8 GB 能用，16 GB 可同时运行全部服务 |
| 磁盘 | 镜像与模型合计约 20—30 GB，建议放在非系统盘 |
| 显卡 | 可选。有 NVIDIA 显卡时文档解析与本地模型会快很多 |
| 网络 | 首次部署需要下载镜像与模型；之后只有网络搜索需要联网 |

### 安装 Docker Desktop

1. 从 [Docker 官网](https://www.docker.com/products/docker-desktop/) 下载安装包，一路「下一步」，保留「Use WSL 2」勾选。
2. 安装完成后按提示重启电脑。
3. 打开 Docker Desktop，同意条款（可以跳过登录），等左下角出现绿色的 **Engine running**。

> **想把数据放到 D 盘？** Docker Desktop「Settings → Resources → Advanced → Disk image location」改到 D 盘任意文件夹即可。服务台的镜像和模型都存在这里。
>
> **开着代理软件？** 在 Docker Desktop「Settings → Resources → Proxies」把 HTTP / HTTPS 代理设成你的代理地址（如 `http://127.0.0.1:7897`），下载镜像和模型会顺畅很多。服务台的各服务容器会自动走 Docker 的代理。

## 2. 安装服务台

在 [Releases](../../../releases) 下载最新的 `知舟服务台_x.y.z_x64-setup.exe`，双击安装（只安装给当前用户，不需要管理员权限）。安装程序会在缺少 WebView2 时自动补上。

打开后先看首页的 **环境体检**：

- 全部是绿色对勾：可以开始部署；
- 有红叉：按那一行的提示处理，处理完点「重新检测」；
- 黄色感叹号（如没有 NVIDIA 显卡、内存偏少）：不影响使用，只是会慢一些。

## 3. 部署服务

进入 **服务目录**，按需要点「安装」。每项服务互不影响，可以只装一部分。

| 服务 | 下载量 | 说明 |
|---|---|---|
| 网络搜索（SearXNG） | 约 400 MB | 最轻，建议先装它熟悉流程 |
| 本地模型（Ollama） | 约 3 GB + 模型 | 装好后在「我的服务 → 本地模型」下载向量模型 |
| 文档解析（MinerU） | 约 6 GB + 首次解析时约 1.2 GB 模型 | 在本机构建镜像，第一次需要 10—20 分钟 |

有 NVIDIA 显卡时，可以在安装前点卡片上的「改用显卡」。

安装完成的服务会出现在 **我的服务**，每项都有四个页签：

- **概览**：启动 / 停止 / 重启、知舟可用性检查、日志、端口与镜像、卸载；
- **设置**：服务专属选项（搜索引擎、解析档位等）；
- **试一试**：直接搜一次、解析一个 PDF，结果就是导入知舟后的样子；
- **使用说明**：这项服务在知舟里怎么用、常见问题。

### 选一个向量模型

在「我的服务 → 本地模型 → 向量模型 · 最新」里挑一个下载。中文知识库推荐：

- `qwen3-embedding`（0.6b 体积小，8b 效果最好但更慢）；
- `bge-m3`（老牌，中英文都不错）。

下载完成后，模型旁会显示维度。支持截取维度的模型（如 qwen3-embedding）可以下拉选一个更小的维度，例如 1024：手机上占用更少、检索更快，效果略降。**改维度后，知舟需要重建一次索引。**

## 4. 连接知舟

1. 手机和电脑连同一个 Wi‑Fi。
2. 服务台进入 **连接知舟**，如果顶部提示「手机可能连不上」，点「允许访问」并在系统弹窗里确认（只对家庭 / 办公网络放行）。
3. 手机打开知舟 **设置 → 连接服务台**，点 **扫码配对**，扫服务台页面上的二维码。
4. 知舟会列出服务台能提供的功能：
   - 文档解析、网络搜索默认勾选；
   - 向量模型默认不勾——勾上后选择模型，配好后需要在知舟「知识检索」里重建索引。
5. 点「连接」，确认将发送的数据后，知舟会逐项配好并显示结果。

扫不了码（比如平板摄像头不便）时，可以在服务台「连接知舟」点「导出配置文件」，把文件内容复制到知舟的「粘贴配对码」里。

也可以不扫码、照「连接知舟」页列出的值手动填写。

## 5. 日常使用

- 关闭窗口时服务台会缩到右下角托盘，网关继续为手机服务；托盘右键「退出」才真正停止。
- 在「设置」里打开「开机自动启动」，手机随时连得上。各服务容器由 Docker Desktop 自动拉起，所以 Docker Desktop 也要设为开机启动。
- 电脑换了网络（IP 变了）或在「连接知舟」更换了 Key，在知舟里重新扫码即可。

## 常见问题

**知舟导入 PDF 一直失败？**
先在服务台「我的服务 → 文档解析 → 试一试」解析同一个文件。能成功说明服务正常，检查手机与电脑是否在同一 Wi‑Fi、防火墙是否已放行；失败则看「概览 → 查看日志」。第一次解析要下载模型，需要多等一会儿。

**解析很慢？**
没有显卡时，标准档每页约 20 秒。可在知舟「设置 → 文档解析」把「模型」从 `standard` 改成 `flash`（只抽文字层，最快，扫描件识别不了）或 `basic`。

**搜索没有结果？**
多半是所选搜索引擎在当前网络下连不上。在「网络搜索 → 设置」多选几个国内引擎；开着代理时可以加上 Google。

**下载镜像或模型失败？**
服务台会自动改用国内镜像源重试。仍失败时，按第 1 节给 Docker Desktop 配置代理，或在服务台「设置 → 下载加速」换一个镜像源。

**知舟提示 Key 不正确？**
服务台「连接知舟」更换过 Key。重新扫码配对即可。

**卸载服务会删掉我的模型吗？**
默认不会，镜像和模型都保留，重装很快。卸载确认框里勾选「同时删除已下载的模型与数据」才会删除。
